# Scope Tesis S2

Dokumen ini mengunci scope `Petualangan Kata` agar tetap aman untuk kebutuhan ujian tesis S2 dan tidak melebar ke fitur yang tidak terlalu membantu penilaian akademik.

## Tujuan Utama

Produk harus cukup untuk menunjukkan bahwa:

- ada media pembelajaran berbasis game,
- lima indikator membaca dasar terwakili,
- peserta bisa menjalani satu sesi lengkap,
- data hasil belajar tercatat,
- pre-test dan post-test bisa dibandingkan.

## Scope Wajib

Bagian ini dianggap cukup untuk demo dan uji penelitian awal:

- kode peserta sederhana
- pre-test
- tutorial singkat
- lima modul permainan
- post-test
- hasil akhir
- penyimpanan data lokal
- sinkronisasi ke PostgreSQL lokal
- dashboard guru sederhana
- export CSV

## Scope Bagus Jika Sempat

Bagian ini boleh ada, tetapi bukan penentu utama kelulusan demo:

- penyempurnaan visual
- penambahan variasi soal
- perbaikan audio instruksi manual
- validasi konten oleh ahli
- per indikator statistik yang lebih detail

## Scope Tidak Wajib Untuk Ujian

Bagian ini sengaja tidak menjadi target utama:

- multiplayer
- AI
- voice recognition
- login kompleks
- manajemen user bertingkat
- CMS bank soal lengkap
- avatar dan koleksi stiker
- dunia game besar
- analitik lanjutan real-time

## Patokan Cukup Untuk Sidang

Prototype dianggap cukup apabila:

1. Peserta bisa masuk dengan kode.
2. Pre-test berjalan.
3. Lima modul bisa dimainkan.
4. Post-test hanya terbuka setelah modul selesai.
5. Hasil peserta tersimpan.
6. Dosen atau penguji bisa melihat rekap nilai.
7. Data bisa diekspor untuk bahan analisis.

## Keputusan Scope

Mulai titik ini, strategi pengembangan adalah:

- utamakan stabilitas dibanding fitur baru,
- utamakan data penelitian dibanding efek visual tambahan,
- utamakan kelancaran demo dibanding kompleksitas sistem.
